Pomodoro Clock (installable PWA)

1. Upload all files in this folder to any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, Vercel).
2. Open the site URL.
   - Android (Chrome): menu > Install app
   - iPhone/iPad (Safari): Share > Add to Home Screen
   - Windows/macOS (Chrome or Edge): install icon in the address bar
It must be served over HTTPS (or localhost); opening index.html from a file will not allow installing.
